# study-archive-2020

## 📝 프로젝트 소개
2020년 실시간 객체 감지(태극기 검출 등) OpenCV 프로젝트와 음성 피치 비교(Pitch Compare) 등 파이썬 공부 기록입니다.

## 🛠 주요 사용 기술
- Python 3
- OpenCV (컴퓨터 비전)
- matplotlib / seaborn (데이터 시각화)
- librosa / scipy (오디오 피치 분석)

## 📂 주요 파일 구성
- `0322_실시간감지`: OpenCV 웹캠 및 비디오 스트림 상에서 특정 물체(태극기 등)를 실시간 감지하는 테스트 코드
- `1129_Pitch Compare`: 주파수 피치 검출 및 두 소리의 피치 데이터 분석/비교 스크립트
- `0429_CSV-IMAGE-검출-FEATURE추출`: CSV 내의 메타데이터를 파싱하여 이미지 내 특징점을 추출하고 시각화하는 도구
